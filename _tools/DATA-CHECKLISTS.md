# Data checklists for watch tools pages

Use these fields before a page can be added. If any required field is missing, leave the model out.

## Lug width by model

Required:
- Brand and model name
- Reference numbers
- Lug width in millimeters, or a clear integrated/proprietary label
- Official or trusted source URL already recorded in the Strap Finder
- Strap Finder model page to link

Optional:
- Case size
- Official watch photo already hosted from the brand, with credit
- Best match strap type drawn from the model's recorded styles

Do not add a lug width that is not already in `_data/straps.json`.

## Available now (no waitlist)

Required:
- Official brand product or lineup URL
- Official list price and currency
- Date the official page was checked
- A clear reason the model is sold without an allocation list (official shop, in stock note, or authorized retail with a published price)
- Reference number as printed by the brand
- Affiliate search terms only after the official source is saved

Optional:
- Current sale price shown on the official page, labeled as a sale
- Lug width, only if already verified
- Official photo already hosted from the brand, with credit

Leave out any model whose current official list price cannot be confirmed. Do not use marketplace asking prices as list prices.

## Service cost guides

Required:
- Official brand service price URL
- Complete service prices as published
- Date the official page was checked
- Currency and market (for example US)
- A short note on what the published fee includes or excludes, taken from the same page

Leave out any brand that does not publish a readable price list. Do not estimate from forums, independent shops, or currency conversions.
